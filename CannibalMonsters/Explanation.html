• Voici une version web du jeu Cannibal Monsters, originalement vendu par Smart Games, mais qui n'est malheureusement plus sur le marché.
  • Le but du jeu est d'empiler des monstres colorés pour n'arriver qu'à une seule pile, tout en respectant la forme de la base de leur base. Les monstres de la même couleur diffèrent par leur nombre d'yeux. Ceci est utilisé pour indiquer les coups.
  • Les règles de superposition sont les suivantes : un monstre rouge peut manger un bleu, un monstre bleu peut manger un vert et un monstre vert, un rouge..
  • Un monstre peut manger le monstre suivant sur la même ligne ou colonne..
  • Dans cette version, les coups autorisés sont indiqués par des flèches.
  • Le panneau inférieur permet de choisir un problème parmi ceux proposés dans le jeu original.
  • Lorsqu’il ne reste plus qu’une seule pile, le système affiche un message de félicitations. Si l’empilement de monstres est impossible, le système indique une impasse.
  • Pour retrouver le problème initial, cliquer sur le même numéro ou sur la flèche courbe bleue en bas à droite.
  • Pour annuler les derniers coups, il suffit de cliquer sur la flèche en bas à gauche.
  • Le système est capable de trouver la solution optimale (c’est-à-dire avec le nombre minimal de déplacements) à partir de la configuration courante. Il faut cliquer sur et l'affichage montre la configuration finale. Les coups sont indiqués par la couleur de la pièce (R: rouge, B:Bleu, G: vert) suivi du nombre d'yeux. Un monstre formé de diverses pièces est représenté par la suite de lettres commençant par la base et se terminant par le nombre d’yeux du monstre situé au-dessus de la pile. Mais essayez plutôt de résoudre le problème par vous-même!
  • Here is a web version of the game Cannibal Monsters, originally sold by Smart Games, but which is unfortunately no longer available.
  • The goal of the game is to stack colored monsters to form a single pile, while matching the shape of the base. Monsters of the same color differ in the number of eyes they have. This is used to determine the order of play.
  • The stacking rules are as follows: a red monster can eat a blue one, a blue monster can eat a green one, and a green monster can eat a red one...
  • A monster can eat the next monster in the same row or column..
  • In this version, allowed moves are indicated by arrows.
  • The bottom panel allows you to choose a problem from those offered in the original game.
  • When only one stack remains, the system displays a congratulatory message. If stacking the monsters is impossible, the system indicates a stalemate.
  • To return to the initial problem, click on the same number or on the blue curved arrow in the bottom right corner.
  • To undo the last moves, simply click on the arrow in the bottom left corner.
  • The system can find the optimal solution (i.e., the one with the fewest moves) based on the current configuration. Click on and the display will show the final configuration. Moves are indicated by the piece’s color (R: red, B: blue, G: green) followed by the number of eyes. A monster made up of various pieces is represented by a sequence of letters starting with the base and ending with the number of eyes on the monster at the top of the stack. But try solving the problem yourself first!
