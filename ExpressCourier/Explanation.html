• Voici une version web du jeu Panique Logistique
  • Le but du jeu est de charger toutes les caisses sur la plateforme des camions de la même couleur et de les faire sortir du jeu.
  • Les camions ne peuvent se déplacer d'une case que sur la ligne ou la colonne sur lesquelles ils sont placés au début du jeu pourvu que la case soit libre.
  • Un camion peut sortir du jeu par une des cases autour du plateau indiquées par une flèche pourvu qu'il soit chargé d'une caisse de sa couleur; une fois sorti, un camion ne peut pas revenir sur le jeu.
  • Une caisse peut être déplacée sur une plateforme adjacente d'un autre camion.
  • À chaque étape, des flèches noires indiquent les mouvements possibles de camions et des flèches bleues, les déplacements d'une caisse. En cliquant sur la flèche, le mouvement correspondant est effectué.
  • Le système affiche un message de félicitations lorsque toutes les caisses ont été enlevées du plateau.
  • Le panneau inférieur permet de choisir un problème parmi ceux proposés dans le jeu original.
  • Pour retrouver le problème initial, il suffit de cliquer sur le même numéro ou sur la flèche courbe bleue en bas à droite.
  • Pour annuler le dernier coup, il suffit de cliquer sur la flèche en bas à gauche.
  • Le système peut déterminer la solution optimale (c’est-à-dire avec le nombre minimal de déplacements) à partir de la configuration courante. Il faut cliquer sur et l'affichage montre la configuration finale.
  • Les déplacements de la solution sont indiqués par une lettre (la première du nom en anglais de la couleur du camion (p. ex. b=blue, p=purple, a=aqua,...) suivie d'une flèche indiquant le déplacement du camion. Si ce mouvement est précédé d'un point d'exclamation, le camion sort du jeu avec sa caisse. Si le mouvement débute par un astérisque, c'est plutôt la caisse de cette couleur qui est déplacée dans la direction de la flèche.

  • Here is a web version of the game ExpressCourier .
  • The goal of the game is to load all the cargos onto the platforms of trucks of the matching color and move them off the board.
  • Trucks can only move one space along the row or column where they started, provided the space is empty.
  • A truck can exit the game via one of the spaces around the board marked with an arrow, provided it is carrying a cargo of its own color; once a truck has exited, it cannot return to the game.
  • A cargo can be moved to an adjacent platform on another truck.
  • At each step, black arrows indicate possible truck movements, while blue arrows indicate cargo movements. Clicking an arrow executes the corresponding move.
  • The system displays a congratulatory message once all the cargos have been removed from the board.
  • The bottom panel allows you to select a puzzle from those included in the original game.
  • The bottom panel allows you to choose a problem from among those offered in the original game.
  • To return to the initial problem, simply click on the same number or on the blue curved arrow at the bottom right.
  • To undo the last few moves, simply click on the arrow at the bottom left.
  • The system is able to find the optimal solution (i.e., with the minimum number of moves) from the current configuration. Click on and the display will show the final configuration.
  • Solution moves are indicated by a letter (the first letter of the truck's color name in English—e.g., b=blue, p=purple, a=aqua, etc.) followed by an arrow indicating the truck's movement. If the move is preceded by an exclamation mark, the truck exits the game along with its crate. If the move begins with an asterisk, it is the cargo of that color that is moved in the direction of the arrow instead.
