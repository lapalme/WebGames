SVG Path Playground Show explanations Hide explanations

  • This page can be used to help develop SVG path definitions, associated with the d attribute of the path element, by default in a unit square. The x and y coordinates are indicated at the bottom and left of the drawing area. The resulting expression is shown at the bottom, which can then copy-pasted into a SVG element.
  • These explanations take for granted that the user is familiar with the SVG path commands. To better understand these commands, visit this excellent tutorial for Paths.
  • Shapes are created by first identifying points and then choosing a command, it is thus a postfix notation.
  • Clicking on the drawing surface adds a new point that can be used in a subsequent command.
  • Clicking on a command button at the top adds a command using the last n points. n depends on the command as shown in the button. Spurious points between the last command and the current one are removed.
  • The first command should be an M to define the first point of the path; otherwise no line will be drawn with the following commands.
  • The command is added to a list at the right of the drawing area. It is a letter followed by one or more text boxes containing the value of a point as two numbers separated by a comma.
  • Dragging an existing point moves it, and the command that uses it is modified accordingly. This might change more than one line.
  • Editing a point in a text box also changes the point and the drawing is updated when the user types a carriage return. If the content of the text box does not correspond to two numbers, the original value is put back in the text box. The input values are rounded according to the specified number of decimals.
  • The A command is different to match its parameters: the first text box corresponds to the rx and ry, the second to the three flags and the third text box to the final point.
  • undo: removes the last command and its points.
  • clear: removes all commands and points.
  • The text area below the drawing area shows the complete list of path commands in a form that can be used as the value of the d parameter for the path element.
  • An existing d command can be parsed and displayed. Only the subset of commands shown on the page is implemented and commands with relative coordinates are not allowed. Parsing ignores everything that is not a command (e single letter) or a number.
  • The viewbox parameters and the number of grid lines can be adjusted at the bottom, but the surface must be a square. reset must be clicked so that these new values take effect. This updates the coordinates at the bottom and left of the drawing area. It also clears the commands and the points.
  • The number of decimals shown in the path can be set for rounding values in the command. This also affects the possible values that can be clicked on the drawing area.
