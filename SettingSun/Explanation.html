• Voici une version web du jeu de L'Âne Rouge, un jeu traditionnel, dont il existe de multiples versions sous différents noms: Klotski, Piano Mover Puzzle. La version physique en bois, rappelée par la représentation choisie ici.
  • Le jeu se présente sous la forme d'un ensemble de tuiles qu'il faut glisser dans un des deux espaces libres, de façon à amener le carré identifié avec un cercle rouge, vers la sortie en bas du plateau.
  • Les flèches indiquent à tout moment les pièces qui peuvent être déplacées. Il suffit d'en cliquer une pour que la pièce soit déplacée.
  • Le panneau inférieur permet de choisir un problème parmi quelques-un de ceux proposés dans cette application web.
  • Pour retrouver le problème initial, il suffit de cliquer sur le même numéro ou sur la flèche courbe bleue en bas à droite.
  • Pour annuler les derniers coups, il suffit de cliquer sur la flèche en bas à gauche.
  • Le système est capable de trouver la solution optimale (c’est-à-dire avec le nombre minimal de déplacements) à partir de la configuration courante. Il faut cliquer sur et l'affichage montre la configuration finale. Attention: certaines solutions, à partir du niveau Avancé, peuvent demander beaucoup de temps de calcul. Chaque coup pour la solution est indiqué par la lettre qui identifie une pièce dans le coin supérieur gauche, suivie d'une ou plusieurs flèches donnant la direction du mouvement. Mais essayez plutôt de résoudre le problème par vous-même!
  • Here is a web version of the game Klotski. This is a traditional puzzle known under many names: Piano Mover puzzle, Pennant Puzzle... My physical wood version is called Setting Sun, it served as inspiration for representation shown here.
  • The game consists of a set of tiles that must be slid into one of the two empty spaces, with the goal of moving the square marked with a red circle toward the exit at the bottom of the board.
  • Arrows indicate which pieces can be moved at any given time. Simply click on an arrow to move the piece.
  • The bottom panel allows you to select a puzzle from some of those offered in this web application.
  • The bottom panel allows you to choose a problem from among those offered in the original game.
  • To return to the initial problem, simply click on the same number or on the blue curved arrow at the bottom right.
  • To undo the last few moves, simply click on the arrow at the bottom left.
  • The system is able to find the optimal solution (i.e., with the minimum number of moves) from the current configuration. Click on and the display will show the final configuration. Warning: some solutions, from the Advanced level, may require a lot of calculation time. Each move for the solution is indicated by the letter that identifies a piece in the upper left corner, followed by one or more arrows giving its movement direction. But try to solve the problem yourself first!
